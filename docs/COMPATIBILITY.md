# Compatibilidade

## Ambiente suportado

- **Jogo:** Treasure of Nadia
- **Plataforma:** Windows
- **Engine identificada:** RPG Maker MV 1.6.1
- **Tradução:** PT-BR v1.0.0
- **Método:** instalação manual por patches delta

## Verificação por hash

A compatibilidade não é inferida apenas pelo número da versão do jogo.

O instalador compara os arquivos locais com os hashes SHA-256 registrados em `payload/release-manifest.json`.

Isso permite distinguir:

- arquivo original compatível;
- arquivo já traduzido;
- arquivo desconhecido ou alterado.

Uma build diferente ou um mod que altere os mesmos arquivos pode ser bloqueado automaticamente.

## Mod managers

Vortex e outros gerenciadores de mods não foram validados para esta versão.

## Saves

O instalador não modifica saves nem dados pessoais do jogador.
